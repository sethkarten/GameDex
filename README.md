# GameDex

GameDex is a Windows application for capturing gameplay video and inputs for AI training.

## Download

Download the latest installer from the [Releases](https://github.com/sethkarten/GameDex/releases/latest) page.

Click on `GameDex_x.x.x_x64-setup.exe` to download.

## Install

1. Run the downloaded `.exe` file
2. If Windows SmartScreen appears, click "More info" → "Run anyway"
3. Follow the installation prompts

## First Launch

1. Open GameDex from the Start Menu or Desktop shortcut
2. Enter your **invite code** and a device name
3. Click Register

## Recommended Settings

- **Resolution:** 720p
- **Frame Rate:** 30 FPS
- **Auto-record:** Enable this to automatically start recording when you launch a game
- **Delete local files after upload:** Enable this to save disk space

## Usage

1. Configure your settings and enable auto-record
2. Play your game - recording starts automatically
3. When finished, go to **Sessions** and click **Upload** to sync to the cloud

## Updates

GameDex automatically checks for updates on launch and will prompt you to install them.
